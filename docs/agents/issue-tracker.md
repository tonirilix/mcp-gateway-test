# Issue tracker: Local Markdown

Issues and specs for this repo live under `.scratch/`.

- Use one directory per feature: `.scratch/<feature-slug>/`.
- Put its spec at `.scratch/<feature-slug>/spec.md`.
- Put implementation issues in `.scratch/<feature-slug>/issues/`, one file per issue, named `NN-<slug>.md` starting at `01`.
- Record triage state in a `Status:` line near the top of each issue.
- Append discussion under a `## Comments` heading.

When a skill says to publish an issue or spec, create the corresponding file here. When it says to fetch a ticket, read the referenced file.
